Goal: make ko-KR, en-US, ja-JP, zh-CN share one canonical prompt block order and constraints. Only locale text/line-breaking/cultural phrase data may differ.

Canonical order:
1. Art Style Director
2. Phrase/Theme semantic data
3. Priority
4. Typography style direction
5. Goal
6. Reference image
7. Character identity lock
8. Art direction + five-axis preset
9. Global sticker composition director
10. Complete slot isolation + safe frame
11. Typography legibility lock
12. Hand/finger stability
13. Panel plan
14. Composition/background
15. Consistency
16. Locale-specific text policy
17. Exclude
18. Final style test

Required locales: ko-KR, en-US, ja-JP, zh-CN.
